# MakeTask Privacy Policy

Last updated: September 12, 2026

## Your tasks stay on your Mac

MakeTask does not collect or transmit your lists, tasks, notes, subtasks, due dates, window positions, or preferences to the developer. There is no MakeTask account, server, advertising, analytics, tracking, or cloud sync.

## Local storage

Lists and tasks are stored in the app's local sandbox using Apple's SwiftData framework. Preferences, such as appearance and keyboard shortcuts, are saved locally using UserDefaults. These preferences are used only to make the app work as you configure it.

## Backups you choose

When you export a backup, MakeTask writes your lists and tasks to a JSON file at a location you choose. The file is not encrypted by MakeTask. Import reads only the backup file you select. If you choose a cloud-synced folder or share a backup, the storage or sharing provider's policies apply. MakeTask does not upload backups itself.

## Retention and deletion

Your data stays on your Mac until you delete it. You can delete tasks and lists within MakeTask. Exported backups are separate files: delete them using Finder, and manage any copies you shared or stored with another provider separately. Device backups may retain copies according to your macOS backup settings. Removing the app does not necessarily remove its local data or exported backups.

## Optional macOS features

Global keyboard shortcuts trigger MakeTask actions; MakeTask does not record what you type in other apps. Launch at Login is optional and controlled through macOS. MakeTask requests file access only when you select an import or export location.

## Support and external links

Opening a support link uses your browser. If you choose to contact the project through GitHub, GitHub processes your account and message under its own privacy policy. Support messages are used to respond to your request. GitHub issues are public, so do not include private tasks, backups, or other sensitive information.

## Contact and changes

Contact the MakeTask project at [GitHub Issues](https://github.com/OrhunMahir/MakeTask/issues). Changes to this policy will be published with an updated date. If a future version introduces data collection, its policy and App Store privacy disclosures will be updated to describe that behavior.
